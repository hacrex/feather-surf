# FeatherSurf promotional branding

This folder contains source-controlled SVG assets for the repository README and
other lightweight project surfaces.

- [`feathersurf-readme-banner.svg`](feathersurf-readme-banner.svg) is the wide
  promotional banner used near the top of the README.
- [`feathersurf-badge.svg`](feathersurf-badge.svg) is a compact badge for
  README sections, project pages, and documentation headers.

Both assets reuse the FeatherSurf feather geometry and the shared navy, sky-blue,
and mint palette. Keep the SVG files editable so future palette or copy changes
do not require rasterization.
