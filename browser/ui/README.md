# Browser UI

Shell UI — address bar, tab strip, menus, settings surfaces, and resource
status indicators.

The shared visual language lives in [`theme/feathersurf.css`](../../theme/feathersurf.css).
The browser-shell reference is available at
[`theme/preview.html`](../../theme/preview.html); it demonstrates the Feather
Night palette, feather-glow backdrop, tab states, address bar, and RAM budget
meter before native shell components are wired to it.

See the top-level [README](../../README.md), [theme guide](../../theme/README.md),
and [docs/roadmap.md](../../docs/roadmap.md) for the component plan.
