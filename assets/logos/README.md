# FeatherSurf logos

The FeatherSurf logo is a simple, forward-leaning feather. Its open silhouette represents light resource use, while the blue and mint strokes represent browsing and privacy working together.

Available marks:

- [`feathersurf-mark.svg`](feathersurf-mark.svg) — preferred source-controlled vector mark.
- [`feathersurf-mark-light.png`](feathersurf-mark-light.png) — transparent mark for light interfaces.
- [`feathersurf-mark-dark.png`](feathersurf-mark-dark.png) — transparent mark for dark interfaces.

Keep the mark clear of nearby controls by at least one-quarter of its rendered
width. Do not stretch, rotate, add a drop shadow, or place it inside a busy
background. The mark is intentionally separate from the wordmark so it remains
recognizable at favicon and compact toolbar sizes.
